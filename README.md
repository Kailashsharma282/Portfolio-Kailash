> Modern Developer Portfolio featuring an **Experience Selector**, **2D Interactive Animated View**, and an **Immersive 3D Three.js Galaxy**.

## 🌟 Experiences Overview

### 1. Landing Page (Experience Selector)
- **Starfield Canvas**: Procedural canvas with animated drifting stars, cosmic nebulas, and parallax depth.
- **3D Tilt Cards**: Interactive glassmorphism cards calculating cursor roll & pitch for 2D vs 3D exploration.
- **Micro-interactions**: Sound effects, glowing borders, and cosmic feature badges.

### 2. 2D Portfolio (Modern, Smooth, Professional)
- **Theme**: Dark futuristic theme with neon accents (`#4f46e5`, `#06b6d4`, `#9333ea`, `#a855f7`).
- **Hero Section**: Dynamic typing roles (`Backend Developer`, `AI Enthusiast`, `Problem Solver`, `Builder`), profile photo with floating badges, call-to-actions, and social links.
- **About & Education**: Background story, values, and formal education at **IIT Kharagpur** (B.Tech Hons, CGPA: 7.37/10).
- **Experience Timeline**: Career milestones at **MeetMux** (Backend & Microservices), **CognifyEV** (Artificial Intelligence), and **Spring Fest, IIT Kharagpur** (Tech Subhead).
- **Featured Projects**: Filterable project showcases (AI Interview Platform, AI Website Builder, Mini Distributed Key-Value Store) with deep-dive architecture modal.
- **Key Achievements**: Interactive celebration cards highlighting Omnixan National Hackathon Finalist (top 4.4k+), Top 1.7% in JEE Main, Top 3.8% in JEE Advanced, and DecodeX Challenge.
- **Skills & Proficiencies**: Categorized tabs with animated progress bars and neon badges.
- **Competitive Programming (CP)**: Dedicated cards with live ratings (LeetCode 1606, Codeforces 1333, CodeChef 3-Star).
- **Interactive Contact**: Working contact form with validation, submission feedback, and direct links.
- **Resume Modal**: Instant printable/downloadable professional resume view.

### 3. 3D Portfolio (Three.js WebGL Galaxy)
- **Galactic Core**: Pulsing energy nexus with rotating wireframe shields.
- **7 Planetary Stations**: Interactive celestial bodies representing each portfolio section (About, Experience, Projects, Achievements, Skills, CP, Contact).
- **Holographic HUD**: Real-time orbital coordinates, station jump dock, and overview resets.
- **Cinematic Transitions**: Smooth camera lerp and warp animations toward clicked planets.
- **Synthesized Ambient Sound**: Pure Web Audio API space synth pad & SFX (no external MP3 dependencies).

## 🚀 Quickstart & Local Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `pnpm`

### Installation
```bash
# Clone or navigate to the repository
cd My-Portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
# Compile TypeScript & bundle with Vite
npm run build

# Preview production build locally
npm run preview
```
